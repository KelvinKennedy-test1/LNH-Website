Firebase Sync Setup

One-time setup (free, ~2 minutes)

  1. Go to console.firebase.google.com and create a project (e.g. limuru-nursing).
  2. In the left menu → Build → Realtime Database → Create database → choose a region → Start in test mode.
  3. Click the gear icon → Project settings → scroll down to "Your apps" → click </> Web → register the app.
  4. Copy the databaseURL value (looks like https://your-project-default-rtdb.firebaseio.com) and paste it below.
